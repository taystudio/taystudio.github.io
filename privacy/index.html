개인정보처리방침

시행일: 2026-04-30 / 최종 개정: 2026-10-06

도구 입력과 접속 정보는 다르게 처리됩니다. 계산기 입력값과 변환할 파일은 브라우저에서 처리합니다. 사이트 방문 시에는 운영 통계, 보안, 광고 서비스를 위한 접속 정보가 처리될 수 있습니다.

1. 도구 입력값과 파일

계산기·텍스트 도구의 입력값과 이미지·PDF·동영상 도구에서 선택한 파일은 브라우저에서 계산·변환하며, 이 처리를 위해 운영자 서버에 업로드하지 않습니다. 일부 도구는 외부 CDN에서 라이브러리·모델·WebAssembly 파일을 내려받습니다. 이때 CDN에는 IP 주소 등 다운로드 요청 정보가 전달됩니다.

2. 접속 통계와 보안

서비스 이용 현황 파악, 오류 수정, 봇 트래픽 구분을 위해 Google Analytics, GoatCounter 및 Cloudflare 기반 자체 통계를 사용합니다. 방문 경로, 접속 시각, 유입 사이트, 기기·브라우저 정보, 국가 정보 등이 처리될 수 있습니다.

자체 통계는 IP 주소와 브라우저 정보를 이용해 날짜별 방문자 식별용 해시를 생성합니다. 방문 기록에는 이 해시와 페이지 경로·접속 시각·유입 사이트·기기 구분·국가·봇 여부를 저장합니다. 404 오류 기록에는 요청 경로, 유입 사이트, 브라우저 정보 및 접속 통신망 정보가 포함됩니다. 도구의 입력 내용과 파일 내용은 이 통계의 수집 항목이 아닙니다.

자체 통계의 원본 기록 보관 설정은 365일이며, 이후 일별 집계 통계를 유지하도록 구성되어 있습니다. 외부 제공자의 처리 및 보관 기준은 각 제공자의 정책을 따릅니다. GoatCounter 개인정보 안내 · Cloudflare 개인정보처리방침

3. 광고와 외부 서비스

Google AdSense와 Kakao AdFit 광고 코드를 사용합니다. 광고 제공 여부는 심사 상태, 지역, 브라우저 설정 등에 따라 달라집니다. Google 등 제3자는 광고 제공·측정 및 부정 이용 방지를 위해 쿠키를 저장하거나 읽고 웹 비콘을 사용할 수 있으며, IP 주소, 브라우저·기기 정보, 방문·광고 상호작용 정보 등을 처리할 수 있습니다.

Google이 파트너 사이트에서 데이터를 사용하는 방식 · Kakao 개인정보처리방침

쿠팡 파트너스 등 외부 링크를 이용하면 해당 사이트의 정책이 적용됩니다. 블로그 댓글은 giscus를 통해 GitHub Discussions에 공개되며, 로그인·계정·댓글 정보는 GitHub에서 처리합니다. 자세한 내용은 블로그 개인정보 안내를 참고하세요.

4. 브라우저 저장과 선택권

테마·언어 등 환경설정에는 localStorage를, 도구 자원과 오프라인 기능에는 브라우저 캐시 등을 사용합니다. 브라우저 설정에서 사이트 데이터와 쿠키를 삭제하거나 차단할 수 있습니다. 일부 기능이 제한될 수 있으며, 쿠키 차단만으로 서버의 접속 기록 처리가 중단되지는 않습니다.

5. 문의와 요청

운영자: TAYSTUDIO / TayLee. 개인정보 처리에 관한 문의·열람·정정·삭제 요청은 feedback@taystudios.com으로 보내주세요. 문의 시 제공한 이메일 주소와 문의 내용은 답변 및 요청 처리에 사용됩니다. 제3자 계정이나 공개 댓글의 관리는 해당 서비스에서도 요청할 수 있습니다.
