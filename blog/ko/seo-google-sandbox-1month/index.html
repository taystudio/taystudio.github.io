배경과 자료의 범위

2026년 5월 9일 taystudio.github.io에서 taystudios.com으로 이전한 뒤 남긴 운영 기록입니다. 아래 수치는 당시 글에 기록한 값이며, 현재 서치콘솔 상태를 의미하지 않습니다. 관측 기간과 각 서비스의 집계 정의가 다르므로 단순 합산하거나 배율을 일반화하지 않아야 합니다.

Bing Webmaster

빙도 비슷한 패턴을 보였습니다. 5/12까지는 옛 도메인의 잔여 데이터가 남아 있었고, 5/22부터 sitemap이 discovered되어 124개 URL이 잡혔습니다. 다만 검색 노출은 0이었습니다. 이 기록만으로 Bing의 평가 방식이나 대기 기간은 알 수 없습니다.

Naver SearchAdvisor (5/22 등록)

여기서 반전이 있었습니다. 5/22 등록 직후부터 spike가 시작됐고, 5/27에 7,600 노출로 정점을 찍은 뒤 5/28 이후로는 일 평균 2,000-3,000 선에서 안정됐습니다. 30일 합계로 보면 노출 26,000에 클릭 230이었습니다.

당시 네이버 유입이 관측됐지만, 위 표만으로 Google과 동일한 기간의 배율이나 검색엔진별 평가 원인을 확정할 수는 없습니다.

Cloudflare Web Analytics

모든 채널을 합친 전체 트래픽은 Cloudflare로 봤습니다. 일 방문이 평균 55명 정도였고, 그중 79%가 네이버/다음 referrer였습니다. ChatGPT referrer도 일부 잡혔습니다. 방문 통계만으로 모든 페이지의 접근 가능 여부나 Google 색인 상태를 확인할 수는 없습니다.

이 기록으로 알 수 있는 것과 없는 것

노출이 올랐다가 줄었다는 사실만으로 Google의 테스트 노출, CTR에 따른 제재, 신규 도메인의 대기 기간을 판정할 수 없습니다. 검색 노출·순위·색인은 서로 다른 지표입니다. 사이트맵에서 URL을 발견한 것과 색인을 생성한 것도 구분해야 합니다.

‘샌드박스’는 신규 사이트의 검색 부진을 설명할 때 쓰이는 비공식 표현입니다. 이 사이트가 특정 제한에 걸렸거나 일정 기간 후 해제된다는 증거로 사용하지 않습니다. 네이버의 초기 유입이 있었다는 기록도 다른 사이트의 즉시 색인을 보장하지 않습니다.

chatgpt.com 유입 경로는 해당 서비스에서 방문이 발생했을 가능성을 보여줍니다. 그것만으로 모델 학습 여부나 Claude·Perplexity의 인용 여부를 확인할 수는 없습니다.

회복 날짜 대신 확인할 항목

광고
  1. 이전 URL이 대응하는 새 URL로 연결되는지 확인합니다.
  2. 새 URL의 응답 상태, robots·noindex 및 canonical을 검사합니다.
  3. 서치콘솔의 집계 보고서와 개별 URL 검사 날짜를 구분합니다.
  4. 수정본을 배포한 시각과 Google의 마지막 크롤링 시각을 비교합니다.
  5. 재크롤링 뒤에도 미색인이면 실제 기능, 콘텐츠의 정확성 및 관련 페이지에서의 연결을 점검합니다.

색인 요청을 반복해도 더 빨리 수집된다고 보장할 수 없으며, 요청 자체가 색인을 보장하지 않습니다. 대기 기간을 정해 놓고 오류 확인을 미루지 않습니다.
