개인정보 처리방침

최종 업데이트: 2026-10-06

1. 접속 통계와 광고

블로그는 Google Analytics, GoatCounter 및 Cloudflare 기반 자체 통계를 사용합니다. 방문 경로·시각·유입 사이트·기기·국가 정보와 날짜별 방문자 해시 등이 처리되며, 해시 생성에는 IP 주소와 브라우저 정보를 사용합니다. 오류 진단용 404 기록에는 브라우저 및 통신망 정보도 포함됩니다. 자체 원본 통계는 365일 보관 후 정리하고 일별 집계를 유지하도록 구성되어 있습니다.

Google AdSense 광고 코드를 포함하며, 광고 제공·측정에 제3자 쿠키와 웹 비콘이 사용될 수 있습니다. Google의 파트너 사이트 데이터 사용 안내를 확인할 수 있습니다.

자세한 수집 항목, 외부 서비스, 보관 및 선택권은 사이트 공통 개인정보처리방침을 따릅니다.

2. 브라우저 저장

테마와 사이드바 접힘 상태 등 환경설정을 localStorage에 저장합니다. 브라우저의 사이트 데이터 삭제 기능으로 초기화할 수 있습니다. 쿠키 차단만으로 서버의 접속 기록 처리가 중단되지는 않습니다.

3. 공개 댓글 — giscus / GitHub

댓글은 giscus를 통해 공개 GitHub Discussions에 저장됩니다. 작성 시 GitHub 로그인이 필요하며 계정명과 댓글은 다른 방문자도 볼 수 있습니다. 민감한 정보를 댓글에 올리지 마세요. 본인 댓글은 GitHub에서 수정·삭제할 수 있습니다. GitHub 개인정보처리방침이 적용됩니다.
